**## 批量端口查询Shell脚本**

&#x20;**# 创建Shell脚本文件**

&#x20;**# 脚本逻辑：**

&#x20;- 定义目标IP地址变量

&#x20;- 定义需要检测的端口列表

&#x20;- 使用循环遍历端口列表

&#x20;- 通过nc命令检测端口是否开放

&#x20;- 输出端口开放/关闭的对应结果

&#x20;**# 给脚本添加可执行权限**

&#x20;**# 运行脚本，测试本地IP的指定端口连通性**

&#x20;**# 调试脚本语法错误，优化输出格式**

**## 脚本源码：**

target\_ip="192.168.213.128"

port\_list=(22 80 3306 8080 6379)

echo "========端口扫描开始========"

for port in ${port\_list\[@]}

do

&#x20;   nc -zv -w 1 $target\_ip $port > /dev/null 2>\&1

&#x20;   if \[ $? -eq 0 ]; then

&#x20;       echo "$target\_ip : $port"

&#x20;   else

&#x20;       echo "$target\_ip : $port"

&#x20;   fi

done

echo "========端口扫描结束========"
