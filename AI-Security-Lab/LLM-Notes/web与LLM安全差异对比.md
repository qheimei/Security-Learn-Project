# Web应用安全 与 LLM大模型安全 差异对比
## 对比维度：
1. 核心攻击目标：
 - Web应用安全：企业业务系统、服务器、数据库，窃取业务数据、控制主机。
 - LLM大模型安全：大模型上下文、知识库、系统预设指令，诱导输出攻击载荷、泄露内部知识库。
2. 漏洞触发位置：
 - Web应用安全：前端页面、后端接口、中间件、数据库、网络传输链路。
 - LLM大模型安全：用户输入Prompt、向量知识库。上下文窗口、插件调用接口、系统Prompt。
3. 典型攻击载荷
 - Web应用安全：SQL注入、XSS跨站、文件上传、SSRF、命令执行、越权访问。
 - LLM大模型安全：Prompt注入、RAG知识库污染、上下文劫持、多对话绕过、Agent插件漏洞。
4. 核心防御技术
 - Web应用安全：WAF、接口权限控制、输入转义、服务器基线、安全开发规划。
 - LLM大模型安全：Prompt清洗、系统Prompt隔离、知识库访问管控、输出内容实时审计、对话长度限制。
5. 技术研究方向
 - Web应用安全：Web、主机、内网、二进制、系统漏洞。
 - LLM大模型安全： LLM攻防、向量库安全、RAG审计、新型Prompt攻击、AI供应链安全。

## 核心区分总结
1. Web安全：针对**程序代码、服务器、网络**的攻击，用于入侵业务系统；
2. LLM安全：针对**模型对话逻辑、知识库**的新型应用层安全，无直接入侵服务器能力，但可泄露内部安全情报、生成攻击脚本。
